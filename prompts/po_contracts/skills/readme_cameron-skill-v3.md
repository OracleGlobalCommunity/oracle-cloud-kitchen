# Cameron Skill Template — Framework para Skills de Especialistas

**Versão 3.0** — Padrão profissional para criar agentes especialistas de alto nível

## Português (PT-BR)

Este framework foi projetado para que qualquer pessoa possa pegar a estrutura da Cameron e adaptar para **qualquer área de conhecimento especializado**.

O grande diferencial é o **esqueleto** (estrutura organizada), que transforma prompts genéricos em skills profissionais, acionáveis e confiáveis.

### Como Usar o Template

1. Copie o arquivo `cameron-skill-v3.md`
2. Renomeie para o nome do seu especialista (ex: `laura-advogada.md`)
3. Substitua o conteúdo das seções com o conhecimento da sua área
4. Ajuste principalmente as seções de Identidade, Never Do e os módulos de conhecimento
5. Teste com casos reais e refine

### Estrutura Recomendada (Mantenha o padrão)

- **0. Context Engineering / Harness + Loop** → Obrigatório
- **1. Identidade** (quem é + tom + Never Do)
- **2. Regras de Atuação**
- **3+ Módulos de Conhecimento** (um por especialidade principal)
  - Visão Geral
  - Discovery Checklist
  - Configuração / Estratégia
  - Melhores Práticas
  - Armadilhas e Erros Comuns
  - Riscos de Projeto
  - Casos de Uso
  - Integrações / Ferramentas
  - Dicas de Campo (o que só quem pratica sabe)
  - Perguntas Difíceis de Clientes
  - Checklist de Testes / Entregáveis
  - Material para Proposta
  - Resumo Executivo

- **Modos Interativos** (Coach, Skill Tester, Entregável)
- **Como Extender a Skill**

### Exemplos de Adaptação

**Advogado Especialista em Direito de Família e Cível**
- Foco em divórcios, guarda de filhos, pensão, inventário, ações indenizatórias, acordos, etc.

**Consultor Financeiro / Trader**
- Foco em Day Trade, Swing Trade, gestão de risco, psicologia do trade, planejamento patrimonial, etc.

Outras áreas possíveis: Medicina, Engenharia, Marketing Digital, Consultoria de Carreira, etc.

## English (EN)

This framework is designed so that anyone can take the Cameron structure and adapt it to **any specialized knowledge domain**.

The biggest value is in the **skeleton** (organized structure), which turns generic prompts into professional, actionable, and reliable skills.

### How to Use the Template

1. Copy `cameron-skill-v3.md`
2. Rename to your specialist's name
3. Replace the sections with your domain knowledge
4. Adjust mainly Identity, Never Do, and Knowledge Modules
5. Test with real cases and refine

### Recommended Structure (Keep the pattern)

- **0. Context Engineering / Harness + Loop** → Mandatory
- **1. Identity** (who + tone + Never Do)
- **2. Operating Rules**
- **3+ Knowledge Modules** (one per main specialty)
  - Overview
  - Discovery Checklist
  - Strategy / Setup
  - Best Practices
  - Common Pitfalls
  - Project Risks
  - Use Cases
  - Integrations / Tools
  - Field Tips
  - Difficult Client Questions
  - Deliverables / Proposals
  - Executive Summary

- **Interactive Modes** (Coach, Skill Tester, Deliverable)
- **How to Extend**

### Adaptation Examples

**Family and Civil Law Lawyer**
- Focus on divorces, child custody, alimony, probate, indemnity actions, agreements, etc.

**Financial Consultant / Trader**
- Focus on Day Trading, Swing Trading, risk management, trading psychology, wealth planning, etc.

Other possible areas: Medicine, Engineering, Digital Marketing, Career Coaching, etc.
